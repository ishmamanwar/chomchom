# ChomChom - Pet Management App

![ChomChom Logo](https://i.imgur.com/1isMEWh.png)

A delightful pet management application built with React frontend and Flask backend.

## Under Construction

This project is currently under active development. Features are being added and refined regularly.

## Features

- **Pet Management**: Add, edit, and manage your pets with photos and details
- **Feeding Schedule**: Track feeding times, food types, and quantities
- **Medication Tracking**: Monitor medication schedules and dosages
- **Vet Appointments**: Calendar-based appointment scheduling with vaccination records
- **Responsive Design**: Works beautifully on desktop and mobile devices
- **Custom UI**: Charming, pet-themed interface with rounded corners and warm colors

## Tech Stack

- **Frontend**: React with TypeScript
- **Backend**: Flask (Python)
- **Styling**: Custom CSS with responsive design

## Getting Started

### Prerequisites

- Node.js (for frontend)
- Python 3.7+ (for backend)
- pip (Python package manager)

### Backend Setup

1. Navigate to the backend directory:

   ```bash
   cd backend
   ```

2. Create and activate a virtual environment (optional but recommended):

   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the Flask server:
   ```bash
   flask run
   ```

The backend will be available at `http://localhost:5000`

### Frontend Setup

1. Navigate to the frontend directory:

   ```bash
   cd frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

The frontend will be available at `http://localhost:3000`
